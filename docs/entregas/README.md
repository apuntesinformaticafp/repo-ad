# Cierres de unidad en el mismo repositorio

UD01 utiliza ahora `ud01/practica.md`, según su [enunciado](../../ud01/enunciado.md).
Este registro se conserva para el material previo de UD02: crea `ud02.md`
siguiendo estos apartados, sin abrir otro repositorio.

1. **Alcance:** operaciones implementadas y limitaciones conocidas.
2. **Ejecución:** versiones, comandos y configuración reproducible.
3. **Comprobaciones:** resultado esperado/observado, pruebas y casos de error.
4. **Decisiones:** por qué se eligió esa solución y qué se revisó.
5. **Procedencia:** qué ejemplos o referencia se consultaron/reutilizaron y cómo.
6. **Demostración:** pasos o enlace privado accesible al docente.
7. **Autoevaluación:** nivel por dimensión de la rúbrica y evidencia que lo respalda.
8. **Cierre:** etiqueta indicada por la práctica, con el patrón
   `practica-ad-NN-vM` (por ejemplo, `practica-ad-01-v1`), creada después del
   commit final.

No insertes el hash del commit final dentro del propio commit: es autorreferente.
La etiqueta y el enlace comunicado al docente identifican el cierre. Una revisión
posterior conserva la etiqueta anterior y usa la siguiente versión del patrón;
por ejemplo, `practica-ad-01-v2` para revisar `practica-ad-01-v1`.
